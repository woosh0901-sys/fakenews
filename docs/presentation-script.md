# 부록 C — 예상 질의응답

**Q. 모순율이 높으면 가짜라는 뜻입니까?**
> 아닙니다. 모순율은 참고 자료와의 불일치 정도이고 판정과는 별개의 축입니다. 근거가 부족해 불일치를 확인할 수 없으면 모순율이 낮아도 '의심'으로 유보합니다.

**Q. 시연 02번은 근거를 못 찾아서 유보한 것입니까?**
> 아닙니다. 근거는 확보했습니다. 다만 확보한 근거가 '근로시간 단축 논의가 진행 중'까지만 말할 뿐, 기사의 핵심 주장인 '내년 전면 도입 확정'을 뒷받침하지 못했습니다. 주무 부처가 확정한 바 없다고 밝힌 점과 1차 공식 자료가 없다는 점을 함께 반영해 유보했습니다.

**Q. 검색 결과가 아예 0건이면 어떻게 됩니까?**
> 그때는 LLM을 호출하지 않고 곧장 '의심'을 부여합니다. 근거가 없다는 것과 거짓이라는 것은 다르기 때문에, 어느 경우든 가짜로 단정하지 않는다는 점은 같습니다.

**Q. Gemini가 응답하지 않으면 서비스가 멈춥니까?**
> 멈추지 않습니다. 1순위 모델이 한도를 초과하면 2순위로 폴백하고, 둘 다 실패하면 판정을 유보한 결과를 반환합니다. 이때 임시 오류 플래그를 붙여 그 결과가 데이터베이스에 저장되지 않도록 막습니다.

**Q. 왜 벡터 데이터베이스를 쓰지 않았습니까?**
> 검증 대상이 '지금 막 나온 뉴스'이기 때문입니다. 미리 색인한 벡터 저장소는 오늘 아침 사건을 담고 있지 않습니다. 사전 색인 대신 실시간 검색 API를 검색 계층으로 쓰고, 검색 품질이 떨어지는 문제를 2단계 본문 재평가로 보완했습니다.

**Q. 개발 환경과 사용 언어는 무엇입니까?**
> 백엔드는 파이썬과 FastAPI, 프론트엔드는 React 19와 Vite, 데이터베이스는 Supabase입니다. 배포는 Vercel 단일 배포이고, 33개의 단위·통합 테스트로 파이프라인을 검증합니다. *(발표에서 뺀 내용이므로 질문이 나올 때만 답하십시오.)*
