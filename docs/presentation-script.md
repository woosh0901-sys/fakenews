# 부록 C — 예상 질의응답

**Q. 모순율이 높으면 가짜라는 뜻입니까?**
> 아닙니다. 모순율은 참고 자료와의 불일치 정도이고 판정과는 별개의 축입니다. 근거가 부족해 불일치를 확인할 수 없으면 모순율이 낮아도 '의심'으로 유보합니다.

**Q. 검색 결과가 하나도 없으면?**
> 가짜로 단정하지 않고 '의심'을 부여합니다. 근거가 없다는 것과 거짓이라는 것은 다르기 때문입니다. 이 경우 LLM 호출도 하지 않습니다.

**Q. Gemini가 응답하지 않으면 서비스가 멈춥니까?**
> 멈추지 않습니다. 1순위 모델이 한도를 초과하면 2순위로 폴백하고, 둘 다 실패하면 판정을 유보한 결과를 반환합니다. 이때 임시 오류 플래그를 붙여 그 결과가 데이터베이스에 저장되지 않도록 막습니다.

**Q. 왜 벡터 데이터베이스를 쓰지 않았습니까?**
> 검증 대상이 '지금 막 나온 뉴스'이기 때문입니다. 미리 색인한 벡터 저장소는 오늘 아침 사건을 담고 있지 않습니다. 사전 색인 대신 실시간 검색 API를 검색 계층으로 쓰고, 검색 품질이 떨어지는 문제를 2단계 본문 재평가로 보완했습니다.

**Q. 같은 기사를 다시 검증하면 결과가 달라집니까?**
> 24시간 안에 '진짜' 판정이 있으면 저장된 결과를 그대로 돌려줍니다. '가짜'와 '의심'은 캐시하지 않고 매번 다시 검증합니다.
